# Asset Naming

画像担当とフロント担当が衝突しないための仮ルールです。

- `ice_dainagon_azuki.png`

## Rule

- ファイル名は小文字、単語区切りは `_`。
- 差し替え時にファイル名を変えない。
- 大きい素材や未使用素材は PR に含めない。
